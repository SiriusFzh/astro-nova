# astro-reader 精读框架

每篇论文精读按以下 7 个维度展开：

## 1. 文献卡片
- 标题 / 作者 / 期刊 / 年份 / DOI / arXiv ID

## 2. 研究背景
- 解决了什么科学问题？
- 已有工作的不足是什么？
- 为什么这个问题重要？

## 3. 方法/技术路线
- 观测/实验/理论方法
- 关键公式与推导
- 数据来源与处理流程
- 代码/软件可用性

## 4. 核心结果
- 主要发现（3-5 个）
- 关键图表解读（Fig.x 说明了什么）
- 数值结果/显著性

## 5. 创新点
- 与已有工作的关键区别
- 方法上的新贡献
- 首次发现/验证

## 6. 局限性
- 方法的局限/假设
- 未解决的问题
- 结果的适用范围

## 7. 个人思考
- 与自身研究的关联
- 可借鉴的方法/思路
- 未来工作方向
- 值得进一步阅读的引用文献
