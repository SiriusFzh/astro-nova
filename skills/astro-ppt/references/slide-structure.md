# astro-ppt 幻灯片结构与模板

## 一、风格选择

| 风格 | 页数 | 语言 | 适用场景 |
|------|------|------|---------|
| **课题汇报** | 10-15 | 中文 | 课题组会、Journal Club |
| **国际会议** | 8-10 | English | AAS/IAU/COSPAR/EWASS |
| **答辩/开题** | 15-20 | 中英混合 | 硕士答辩、博士开题、基金申请 |

---

## 二、课题汇报模板 (10-15页)

适用于课题组会、Journal Club、读书报告。

```
┌──────────────────────────────────────────────────────┐
│ Slide 1   封面                                       │
│   • 论文标题 (中英文)                                 │
│   • 作者 / 期刊 / 年份 / arXiv ID                    │
│   • 汇报人 / 日期                                    │
├──────────────────────────────────────────────────────┤
│ Slide 2   目录                                       │
│   1. 研究背景与科学问题                               │
│   2. 观测/数据与方法                                  │
│   3. 关键结果                                        │
│   4. 讨论与思考                                      │
├──────────────────────────────────────────────────────┤
│ Slide 3-4   研究背景                                  │
│   • 科学问题：解决了什么？                            │
│   • 已有进展与不足                                    │
│   • 本文目标                                          │
├──────────────────────────────────────────────────────┤
│ Slide 5-6   观测/数据/方法                            │
│   • 望远镜/仪器/样本                                  │
│   • 数据处理流程或关键方法                            │
│   • 公式/示意图                                       │
├──────────────────────────────────────────────────────┤
│ Slide 7-10   关键结果 (每页一个核心图)                │
│   • 每个结果一页，一个大图 + 2-3个要点 bullet         │
│   • 图注完整，可独立理解                              │
├──────────────────────────────────────────────────────┤
│ Slide 11   讨论                                       │
│   • 结果解释                                          │
│   • 与已有工作的对比                                  │
├──────────────────────────────────────────────────────┤
│ Slide 12   结论与展望                                  │
│   • 3-5 条核心结论                                    │
│   • 未来工作方向                                      │
├──────────────────────────────────────────────────────┤
│ Slide 13   My思考 (课题组会特色)                       │
│   • 这篇论文对自己工作的启发                          │
│   • 可以借鉴的方法                                    │
│   • 疑问/批评                                         │
├──────────────────────────────────────────────────────┤
│ Slide 14   参考文献 / 致谢                            │
└──────────────────────────────────────────────────────┘
```

## 三、国际会议模板 (8-10页)

适用于 AAS Meeting, IAU Symposium, COSPAR 等。

```
┌──────────────────────────────────────────────────────┐
│ Slide 1   Title Slide                                │
│   • Title (concise, <100 chars)                      │
│   • Authors + Affiliations                           │
│   • Contact / arXiv ID                               │
├──────────────────────────────────────────────────────┤
│ Slide 2   Motivation & Science Question              │
│   • One slide: the gap + the question                │
├──────────────────────────────────────────────────────┤
│ Slide 3   Observations / Data / Method               │
│   • Telescope, sample size, key parameters           │
│   • One key equation or diagram                      │
├──────────────────────────────────────────────────────┤
│ Slide 4-6   Key Results (1 figure per slide)         │
│   • Maximize figure size                             │
│   • 2-3 bullet takeaways per slide                   │
│   • Use consistent color scheme                      │
├──────────────────────────────────────────────────────┤
│ Slide 7   Discussion / Interpretation                │
├──────────────────────────────────────────────────────┤
│ Slide 8   Summary & Outlook                          │
│   • 3 bullet conclusions                             │
│   • Next steps / ongoing work                        │
├──────────────────────────────────────────────────────┤
│ Slide 9   Backup / Acknowledgments                   │
│   • Extra slides for Q&A                             │
└──────────────────────────────────────────────────────┘
```

```
│   • 日期                                              │
├──────────────────────────────────────────────────────┤
│ Slide 2   汇报框架                                    │
├──────────────────────────────────────────────────────┤
│ Slide 3-5   研究背景与意义                            │
│   • 领域背景                                          │
│   • 科学问题                                          │
│   • 研究目标与创新点                                  │
├──────────────────────────────────────────────────────┤
│ Slide 6-8   研究内容与方法                            │
│   • 技术路线图                                        │
│   • 核心方法 / 实验 / 理论                            │
├──────────────────────────────────────────────────────┤
│ Slide 9-13   主要结果 (每页1-2个核心图)               │
│   • 完整的数据展示                                    │
│   • 与已有结果的对比                                  │
├──────────────────────────────────────────────────────┤
│ Slide 14   讨论                                        │
├──────────────────────────────────────────────────────┤
│ Slide 15   结论与创新点                                │
│   • 创新点列条                                        │
│   • 核心结论                                          │
├──────────────────────────────────────────────────────┤
│ Slide 16   展望 / 下一步计划                          │
├──────────────────────────────────────────────────────┤
│ Slide 17   致谢 / Q&A                                │
├──────────────────────────────────────────────────────┤
│ Slide 18+   备份页 (补充图/数据)                     │
└──────────────────────────────────────────────────────┘
```

## 五、排版规范

### Marp 格式

```markdown
---
marp: true
theme: uncover
class:
  - lead
paginate: true
---

# 标题

作者 | 单位 | 日期

---

## 研究背景

- bullet 1
- bullet 2

![width:600px](fig1.pdf)
```

### Pandoc 格式

```markdown
---
title: "论文标题"
author: "汇报人"
date: \today
lang: zh-CN
---

# 研究背景

...

# 方法

...
```

### Reveal.js 格式

```markdown
# 标题

作者

---

## 幻灯片 2

内容
```
