# 天文学常用公式 (Astronomy Formulas)

## 天体测量与坐标
- 时角 H = LST - α  (LST: 地方恒星时, α: 赤经)
- 高度角 sin h = sin φ sin δ + cos φ cos δ cos H  (φ: 纬度, δ: 赤纬)
- 方位角 tan A = sin H / (cos H sin φ - tan δ cos φ)
- 黄赤交角 ε ≈ 23°26' (约 23.44°)

## 恒星参数
- 光度 L = 4πR^2 σ T_eff^4
- 绝对星等 M = m - 5 log(d/10 pc)
- 距离模数 m - M = 5 log(d) - 5  (d 单位为 pc)
- 斯特藩-玻尔兹曼定律: L ∝ R^2 T^4
- 维恩位移定律: λ_max T = 2.898 × 10^{-3} m·K
- 谱线多普勒位移: Δλ/λ_0 = v_r/c
- 恒星自转展宽: Δv = v sin i

## 双星系统
- 开普勒第三定律: P^2 = 4π^2 a^3 / [G(M_1 + M_2)]
- 质心: a_1 / a_2 = M_2 / M_1
- 质函数 f(M) = (M_2^3 sin^3 i) / (M_1 + M_2)^2 = PK^3 / (2πG)
- 轨道速度: v = √[G(M_1 + M_2)(2/r - 1/a)]

## 辐射机制
- 黑体辐射: B_ν(T) = (2hν^3/c^2) / [exp(hν/k_B T) - 1]
- 同步辐射功率: P = (4/3) σ_T c γ^2 β^2 U_B  (σ_T: Thomson截面, U_B: 磁场能量密度)
- 同步辐射特征频率: ν_c = (3/4π) γ^2 eB / (m_e c)
- 轫致辐射 (自由-自由): ε_ff ∝ n_e n_i Z^2 T^{-1/2} exp(-hν/k_B T)
- 逆康普顿散射功率: P_IC = (4/3) σ_T c γ^2 U_ph  (U_ph: 光子能量密度)
- 罗素-米尔关系 (超新星): t_rise ∝ M_ej^{1/2} E_k^{-1/2}

## 宇宙学
- 哈勃定律: v = H_0 d
- 红移: 1 + z = λ_obs / λ_emit
- 光度距离 (平坦宇宙): d_L = (c/H_0)(1+z) ∫_0^z dz' / √[Ω_m(1+z')^3 + Ω_Λ]
- 角直径距离: d_A = d_L / (1+z)^2
- 弗里德曼方程: H^2 = (8πG/3)ρ - kc^2/a^2 + Λc^2/3
- 临界密度: ρ_c = 3H_0^2/(8πG)
- 退行速度: v_rec = H_0 d
- 共动距离: d_c = c ∫_0^z dz'/H(z')

## 暗物质晕
- NFW 轮廓: ρ(r) = ρ_0 / [(r/r_s)(1 + r/r_s)^2]
- 等温球: ρ(r) = σ_v^2 / (2πG r^2)
- 维里定理: 2K + U = 0  (动能与势能)

## 吸积盘
- 爱丁顿光度: L_Edd = 4πGMm_p c / σ_T ≈ 1.3 × 10^{38} (M/M_⊙) erg/s
- 爱丁顿吸积率: Ṁ_Edd = L_Edd / (ηc^2)
- 史瓦西半径: R_S = 2GM/c^2
- ISCO (Schwarzschild BH): R_ISCO = 6GM/c^2 = 3R_S
- Shakura-Sunyaev α盘: ν = α c_s H
- 盘温度分布: T(r) ∝ r^{-3/4}

## 引力波
- 啁啾质量: M_c = (M_1 M_2)^{3/5} / (M_1 + M_2)^{1/5}
- 引力波频率演化: df/dt = (96/5) π^{8/3} (G M_c/c^3)^{5/3} f^{11/3}
- 应变幅度: h = (4/d_L) (G M_c/c^2)^{5/3} (πf/c)^{2/3}
- 并合时间: τ_merge = (5/256) (c^5/G^3) (πf)^{-8/3} M_c^{-5/3}

## 望远镜
- 角分辨率: θ = 1.22 λ / D (瑞利判据)
- 焦比: f/# = 焦距 / 口径
- 集光力 ∝ D^2
- 视场: FOV = (探测器尺寸 / 焦距) × 206265 (arcsec)
- 极限星等: m_lim ∝ 5 log(D) + 常数
- 信噪比: SNR = S / √(S + N_pix (B + D + R^2))
